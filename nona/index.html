Jeu de cartes – Humain vs IA

Ce projet simule un jeu de cartes entre un joueur humain et une IA. Le but est de lancer plusieurs parties automatiquement pour comparer les taux de victoire de l'ia

1. Structure du projet

Le projet est découpé en plusieurs fichiers :

  • Carte.py : Classe carte
  • Player.py : Classe joueur
  • tools.py : logique d’une partie
  • main.py : simulation de plusieurs parties et stat

2. La classe Carte

Chaque carte possède : - une valeur - une forme

Code

class Carte:
    def __init__(self, value: int, shape: str):
        self.value = value
        self.shape = shape

    def __str__(self):
        return f"{self.shape} {self.value}"
  • value sert à comparer les cartes entre elles
  • shape est uniquement descriptive (ex: "R", "C")
  • la méthode __str__ elle permet juste de rendre l'affichage lisible

3. La classe Player

Un joueur possède : - un nom - et des cartes (hand)

Code

from Carte import Carte

class Player:
    def __init__(self, name: str):
        self.name = name
        self.hand = []

    def __str__(self):
        return self.name + ": " + ", " + str([str(carte) for carte in self.hand])

    def play(self):
        return self.hand.pop(-1)

Création de la classe Player qui permettra de créer les joueurs IA/Humain

4. La partie partie (partie())

La fonction partie() gère la partie.

Création de la pioche

pioche = [
    Carte(0,"R"),
    Carte(1,"R"),
    Carte(2,"R"),
    Carte(3,"R"),
    Carte(4,"R"),
    Carte(1,"C"),
    Carte(2,"C"),
    Carte(3,"C"),
    Carte(4,"C"),
    Carte(5,"C"),
]

- Le paquet contient 10 cartes

Mélange et distribution

random.shuffle(pioche)

human = Player("human")
ai = Player("ai")

while len(pioche) > 0:
    carte = pioche.pop(-1)
    human.hand.append(carte)
    carte = pioche.pop(-1)
    ai.hand.append(carte)
  • Le paquet est mélangé aléatoirement
  • Chaque joueur reçoit 5 cartes

Les tours de jeu

points_human = 0
points_ai = 0

for _ in range(nb_tour):
    carte_human = human.play()
    carte_ai = ai.play()
  • Ils jouent une carte chacun
  • Cartes comparées par leur valeur

Attribution des points

if carte_human.value > carte_ai.value:
    points_human += 1
else:
    points_ai += 1
  • La carte la plus forte gagne le point
  • Si égalité, l’IA gagne le point

Condition de victoire

if points_human >= 3:
    return 'human'
elif points_ai >= 3:
    return 'ai'
  • Le premier joueur à atteindre 3 points gagne la partie
  • La fonction retourne le nom du gagnant

5. Simulation de plusieurs parties (main.py)

Le fichier principal sert à mesurer les perf sur un grand nombre de parties.

Code

victoire_ai = 0
victoire_human = 0

nombre_tour = 1000
for _ in range(nombre_tour):
    gagnant = partie()
    if gagnant == 'ai':
        victoire_ai += 1
    else:
        victoire_human += 1

Affichage des résultats

print(f"L'IA a gagné {victoire_ai} parties")
print(f"L'humain a gagné {victoire_human} parties")
print("Pourcentage victoire AI :", victoire_ai / nombre_tour * 100)
  • Le nombre total de victoires est affiché
  • Le pourcentage de victoire de l’IA est calculé
