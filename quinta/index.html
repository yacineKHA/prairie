Projet SQL – Gestion des villes et des personnes

Ce projet consiste à créer une base de données relationnelle avec différentes requêtes SQL pour exploiter ces données.

1. Création des tables

Table city

CREATE TABLE city (
    id INT PRIMARY KEY,
    name VARCHAR NOT NULL,
    lat FLOAT,
    lon FLOAT
);

Cette table stocke : - le nom de la ville - sa latitude - sa longitude

Table people

CREATE TABLE people (
    id INT PRIMARY KEY,
    city INT,
    name VARCHAR NOT NULL,
    height FLOAT,
    date_of_birth DATE,
    place_of_birth INT,
    FOREIGN KEY (city) REFERENCES city(id),
    FOREIGN KEY (place_of_birth) REFERENCES city(id)
);

Table people avec : - leur nom - leur taille - leur date de naissance - leur ville de résidence - leur ville de naissance

2. Ajouter une ville

INSERT INTO city (name, lat, lon) 
VALUES ('Toulouse', 43.6047, 1.4442);

Cette requête permet d’ajouter une ville + ses coordonnées GPS.

3. Ajouter une personne

INSERT INTO people (city, name, height, date_of_birth, place_of_birth) 
VALUES (1, 'Jojo', 1.75, '1990-05-15', 1);

4. Ajouter plusieurs personnes d’un coup

INSERT INTO people (city, name, height, date_of_birth, place_of_birth) 
VALUES 
    (1, 'Personne 1', 1.75, '1990-01-01', 1),
    (2, 'Personne 2', 1.80, '1985-05-15', 2),
    (1, 'Personne 3', 1.65, '1992-08-20', 3),
    (1, 'Personne 20', 1.65, '1992-08-20', 3);

Cette requête permet d’insérer plusieurs lignes en une seule requête.

5. Récupérer la liste de toutes les personnes

SELECT * FROM people;

6. Trier les personnes de la plus vieille à la plus jeune

SELECT * FROM people 
ORDER BY date_of_birth ASC;

7. Trier les personnes de la plus petite à la plus grande

SELECT * FROM people 
ORDER BY height ASC;

8. Afficher les personnes avec leur ville de naissance

SELECT p.*, c.name AS ville_naissance
FROM people p
LEFT JOIN city c ON p.place_of_birth = c.id;

Jointure entre people et city pour récup le nom de la ville.

9. Regrouper les personnes par ville habitée

SELECT p.*, c.name AS ville_residence
FROM people p
LEFT JOIN city c ON p.city = c.id
ORDER BY c.name;

Cette requête permet d’afficher les habitants regroupés par ville.
