Réponses aux questions HTTP / URL

C’est quoi une requête HTTP ?

Une requête HTTP est une communication entre un client et un serveur basée sur le protocole HTTP.
Elle permet de demander ou d’envoyer des données sur le web.

C’est quoi un DNS ?

Le DNS (Domain Name System) permet de traduire un nom de domaine lisible (ex: google.com)
en adresse IP compréhensible par les machines.

C’est quoi GET ?

GET est une méthode HTTP utilisée pour récupérer des données depuis un serveur,
sans modifier la ressource.

C’est quoi https:// ?

C’est le schéma (protocole) de l’URL.
HTTPS est la version sécurisée de HTTP (chiffrement TLS).

C’est quoi dummyjson.com ?

C’est le nom de domaine du serveur contacté
(host du serveur).

C’est quoi 443 ?

C’est le port du serveur utilisé pour les connexions HTTPS.

C’est quoi recipes ?

C’est le chemin (endpoint) vers la ressource demandée sur le serveur.

C’est quoi ? dans une URL ?

Il sert à introduire les paramètres de requête (query parameters).

C’est quoi limit ?

C’est un paramètre de requête permettant de limiter le nombre d’éléments retournés.

C’est quoi 10 ?

C’est la valeur du paramètre limit :
le nombre maximum d’éléments demandés.

C’est quoi HTTP/2 ?

C’est la version du protocole HTTP utilisée pour la communication
(plus rapide et optimisée que HTTP/1.1).

Que contient la réponse à cette requête ?

La réponse contient un tableau de recettes au format JSON.
