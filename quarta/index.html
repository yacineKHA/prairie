Création de groupes d’élèves

Ce projet permet de répartir aléatoirement des élèves dans des groupes.

Liste des élèves

eleves = ["a", "b", "c", "d", "e"]

Taille des groupes

k = 2
n = len(eleves)
  • k : nombre maximum d’élèves par groupe
  • n : nombre total d’élèves

Calcul du nombre de groupes

nb_de_grp = math.ceil(n / k)
print("nb de groupe", nb_de_grp)

Initialisation des groupes

groupes = []

for i in range(nb_de_grp):
    groupes.append([])

Chaque groupe est représenté par une liste vide.

Tirage aléatoire

while len(eleves) > 0:
    indice_au_hazard = random.randrange(0, len(eleves))
    eleve = eleves[indice_au_hazard]
    eleves.remove(eleve)

Un élève est choisi au hasard puis retiré de la liste.

Affectation dans un groupe aléatoire

groupe_hazard = random.randrange(0, nb_de_grp)

while len(groupes[groupe_hazard]) == k:
    groupe_hazard = random.randrange(0, nb_de_grp)

groupes[groupe_hazard].append(eleve)

L’élève est ajouté dans un groupe non complet.
