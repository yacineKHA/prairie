Apprentissage automatique – Prédiction avec arbre de décision

Le but du projet : on génère des données au hasard, on calcule la bonne réponse, et on entraîne un arbre de décision pour qu'il apprenne à trouver la réponse tout seul.

1. Génération des données (ashGen.py)

Ce fichier crée un tableau de données aléatoires.

Chaque ligne c'est un essai avec : - Les réponses de 4 complices (a, b, c, d) - 3 barres de tailles différentes (1, 2, 3) - La barre de référence (ref) - La réponse du vrai participant (v) qu'on remplira après

Code de génération

import random
import pandas as pd


def generate(n):
    ash_keys = ['a', 'b', 'c', 'd', 'v', '1', '2', '3', 'ref']
    df = pd.DataFrame(columns=ash_keys)

    for i in range(n):
        bars = set()
        while len(bars) < 3:
            bars.add(random.randrange(1, 11))

        bars = list(bars)
        bonne_reponse = random.randrange(1, 4)
        ref = bars[bonne_reponse - 1]

        choix_des_complices = random.randrange(1, 4)
        while bars[choix_des_complices - 1] == ref:
            choix_des_complices = random.randrange(1, 4)

        ligne = [
            choix_des_complices,
            choix_des_complices,
            choix_des_complices,
            choix_des_complices,
            None,
            bars[0],
            bars[1],
            bars[2],
            ref
        ]

        autre_df = pd.DataFrame([ligne], columns=ash_keys)
        df = pd.concat([df, autre_df])

    return df

En gros, à chaque tour on crée 3 barres avec des tailles différentes. On en choisit une au hasard comme bonne réponse, et on la met dans ref. Les complices eux, ils donnent tous la même réponse, mais une mauvaise exprès. La colonne v reste vide pour l'instant.

2. Résolution (solver.py)

On connaît déjà la réponse, donc on compare juste les barres avec la référence.

Trouver la bonne réponse

def solve(line):
    if line['1'] == line['ref']:
        return 1
    if line['2'] == line['ref']:
        return 2
    return 3

On regarde quelle barre a la même taille que la référence, et c'est notre réponse. (pas d'ia juste logique)

Remplir tout le tableau

def solveDf(df):
    df['v'] = df.apply(solve, axis=1)
    return df

Ça applique la fonction solve sur chaque ligne et remplit la colonne v automatiquement.

3. Entraînement de l'arbre (main.py)

C'est ici qu'on fait tourner tout le projet : on génère les données, on entraîne l'arbre, et on regarde ce qu'il donne.

On génère et on résout

df = generate(1)
result = solve(df.loc[0])

df = generate(10)
solved = solveDf(df)

On entraîne l'arbre

inputs = df[['a', 'b', 'c', 'd', '1', '2', '3', 'ref']]
output = df[['v']]

arbre = tree.DecisionTreeClassifier()
arbre = arbre.fit(inputs, output)

inputs c'est ce que l'arbre voit (les réponses des complices + les barres), et output c'est ce qu'il doit deviner (la bonne réponse). On lui donne tout ça et il apprend.

On affiche l'arbre

tree.plot_tree(arbre)
plt.show()

Ça permet de visualiser comment l'arbre prend ses décisions.

4. Test du modèle

On vérifie si l'arbre a bien appris.

On génère de nouvelles données

dfTest = generate(1000)

1000 nouveaux essais que l'arbre n'a jamais vus.

L'arbre fait ses prédictions

repArbre = arbre.predict(
    dfTest[['a', 'b', 'c', 'd', '1', '2', '3', 'ref']]
)

On calcule le score

bonnesReponses = dfTestSolved[

On compare ce que l'arbre a prédit avec les vraies réponses. Le résultat c'est le pourcentage de réussite.
